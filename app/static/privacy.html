Privacidad y términos

Borrador. Este texto describe cómo funciona hoy el servicio. Está pendiente de revisión por un contador o abogado y puede cambiar antes de que se firme un acuerdo con un cliente. Hasta entonces, no cargues documentos con datos personales o confidenciales.

Qué guardamos

  • Documentos del cliente: el texto extraído de los archivos que subís (.md, .txt, .pdf, .docx), dividido en fragmentos, con el nombre del archivo y la fecha de carga. El archivo original no se conserva.
  • Preguntas: el texto de cada pregunta hecha al asistente, si se pudo responder, qué documento fue el principal y si el usuario marcó la respuesta como útil o no. No guardamos la dirección IP ni datos del visitante.
  • Claves: la clave secreta se guarda solo como hash; no podemos recuperarla. La clave pública del widget solo permite hacer preguntas.

Quién procesa los datos

  • El servicio corre en Render y la base de datos en Neon (PostgreSQL). Son proveedores externos, y los datos se almacenan en sus servidores.
  • Si el cliente usa respuestas redactadas con IA, la pregunta y los fragmentos relevantes de sus documentos se envían a la API de Anthropic para generar la respuesta. Si no está activada, no se envía nada a Anthropic y se muestran los fragmentos citados.
  • Los documentos de un cliente nunca se usan para responder a otro cliente. No vendemos datos ni los usamos para publicidad.

Control y borrado

  • Podés borrar cualquier documento desde el panel en cualquier momento.
  • Si terminás la prueba, pedinos por email el borrado completo de tu cliente (documentos, preguntas y claves) y lo hacemos y te lo confirmamos.
  • Las preguntas registradas se conservan mientras dure la relación con el cliente. Todavía no hay borrado automático.

Condiciones de uso

  • El servicio está en fase de prueba y se ofrece tal cual está, sin garantía de disponibilidad. Las respuestas pueden ser incorrectas: siempre muestran sus fuentes para que se verifiquen.
  • Solo subí documentos que tenés derecho a usar. No subas contraseñas, datos de tarjetas ni datos personales de terceros.
  • Podemos suspender una cuenta que haga un uso abusivo del servicio.

Privacy and terms

Draft. This text describes how the service works today. It is pending review by an accountant or lawyer and may change before an agreement is signed with a client. Until then, please do not upload documents containing personal or confidential data.

What we store

  • Client documents: the text extracted from the files you upload (.md, .txt, .pdf, .docx), split into chunks, with the file name and upload date. The original file is not kept.
  • Questions: the text of each question asked to the assistant, whether it could be answered, which document was the top match, and whether the user rated the answer helpful. We do not store IP addresses or visitor details.
  • Keys: the secret key is stored only as a hash and cannot be recovered. The public widget key can only ask questions.

Who processes the data

  • The service runs on Render and the database on Neon (PostgreSQL). They are third-party providers and the data is stored on their servers.
  • If the client uses AI-written answers, the question and the relevant chunks of their documents are sent to the Anthropic API to write the answer. If it is turned off, nothing is sent to Anthropic and the cited passages are shown instead.
  • One client's documents are never used to answer another client. We do not sell data or use it for advertising.

Control and deletion

  • You can delete any document from the panel at any time.
  • If you end the trial, email us to delete your whole client (documents, questions and keys); we will do it and confirm.
  • Logged questions are kept for as long as the client relationship lasts. There is no automatic deletion yet.

Terms of use

  • The service is in a trial phase and provided as is, with no uptime guarantee. Answers can be wrong: they always show their sources so they can be checked.
  • Only upload documents you have the right to use. Do not upload passwords, card data or third-party personal data.
  • We may suspend an account that abuses the service.
