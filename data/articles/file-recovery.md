---
title: Recovering deleted or overwritten files
---
## Deleted files
Check the Recycle Bin first and restore the item from there. Files removed from a network drive do not go to the Recycle Bin, but the service desk can restore them from the nightly backup if the file existed the day before. Tell them the full path and the approximate time of deletion.

## Previous versions
Right-click the file or its folder, choose Properties and open the Previous Versions tab to roll back to an earlier copy. Files stored in the company cloud storage keep a version history: open the file's menu and choose Version history to restore an older version.

## Unsaved documents
Office applications keep recovery copies. Reopen the application and look for the Document Recovery pane, or use File, Info, Manage Document, Recover Unsaved Documents. Stop using the drive if the file was on a damaged disk and call the service desk.
