---
title: Sending large files
---
## Email limits
Email attachments are limited to 25 MB in total. Messages with larger files bounce back with a delivery failure notice.

## Share a link instead
Upload the file to the company cloud storage, select Share and copy the link. Set the link to specific people for confidential material, and set an expiry date. Files above 100 MB can be uploaded in the browser, which handles interruptions better than the desktop app.

## Sharing with customers
For external recipients use the secure transfer portal. It supports files up to 5 GB and sends a download link with a password. Compressing the file in a zip folder often helps with documents and images, but not with video.
